# Wazuh SIEM Lab – Security Monitoring and Threat Detection

## 1. Project Overview

This project demonstrates the deployment and configuration of Wazuh, an open-source Security Information and Event Management (SIEM) platform.

The objective is to monitor endpoints, collect security events, detect suspicious activities, and monitor file integrity.

## 2. Lab Environment

| Component | Description |
|---|---|
| SIEM Platform | Wazuh |
| Server | Ubuntu Linux |
| Endpoint 1 | Kali Linux |
| Endpoint 2 | Windows |
| Virtualization | VMware |
| Attacker/Testing Machine | Kali Linux |

## 3. Implementation

### A. Wazuh Installation
- Installed and configured the Wazuh server.
- Accessed the Wazuh dashboard.
- Configured endpoint monitoring.

### B. Agent Management
- Connected Kali and Windows agents.
- Checked agent connectivity and status.
- Practiced adding and removing agents.

### C. File Integrity Monitoring (FIM)
- Configured file integrity monitoring.
- Monitored selected directories.
- Practiced detecting file creation, modification, and deletion.

### D. Security Monitoring
- Monitored security events from connected endpoints.
- Explored alerts through the Wazuh dashboard.
- Practiced identifying suspicious activities.

### E. Malware Detection
- Explored Wazuh detection capabilities.
- Tested security monitoring and detection using controlled lab activities.
