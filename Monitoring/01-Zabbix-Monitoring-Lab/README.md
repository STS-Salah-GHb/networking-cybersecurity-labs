# Zabbix Network and Infrastructure Monitoring Lab

## 1. Project Overview

This project demonstrates the installation, configuration, and use of Zabbix for monitoring IT infrastructure and system performance.

Zabbix provides real-time monitoring, performance metrics, host availability information, and problem detection through a web dashboard.

## 2. Lab Environment

| Component | Configuration |
|---|---|
| Monitoring Platform | Zabbix |
| Zabbix Version | 7.4.15 |
| Server OS | Ubuntu Linux |
| Virtualization | VMware Workstation |
| Dashboard | Zabbix Web Interface |

## 3. Implementation

### A. Zabbix Installation
- Installed Zabbix Server on Ubuntu.
- Configured the Zabbix web interface.
- Accessed the monitoring dashboard.

### B. System Monitoring
- Monitored CPU utilization.
- Monitored memory utilization.
- Viewed system performance information.
- Checked host availability.

### C. Problem Monitoring
- Observed problems through the Zabbix dashboard.
- Explored problem severity levels.
- Reviewed system alerts and performance warnings.

## 4. Monitoring Dashboard

The dashboard provides information about:
- Host availability.
- CPU utilization.
- Memory utilization.
- System information.
- Current problems and severity.
- Monitoring statistics.
