# Cisco Access Control Lists (ACL) Configuration Lab

## 1. Project Overview

This lab demonstrates the configuration of Standard and Extended Access Control Lists on Cisco routers to control network traffic.

## 2. Objectives

- Understand Standard and Extended ACLs.
- Configure permit and deny rules.
- Apply ACLs to router interfaces.
- Filter traffic using source and destination IP addresses.
- Control traffic using protocols and port numbers.

## 3. ACL Types

**Standard ACL**
- Filters traffic based on the source IP address.
- Uses numbered ranges 1–99 or 1300–1999.

**Extended ACL**
- Filters traffic based on source and destination IP addresses, protocols, and port numbers.
- Uses numbered ranges 100–199 or 2000–2699.

## 4. Technologies Used

- Cisco Packet Tracer
- Cisco Routers
- IPv4
- Standard ACLs
- Extended ACLs

## 6. Learning Outcomes

- Implementing network access-control policies.
- Filtering network traffic.
- Understanding ACL placement and direction.
- Troubleshooting access-control rules.

## 7. Conclusion

This lab provided practical experience configuring Standard and Extended ACLs to improve network traffic control and security.
